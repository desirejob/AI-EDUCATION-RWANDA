# Contexte rwandais pour les exemples

Les exemples utilisent le franc rwandais (RWF), des cahiers d'école et des achats au marché pour rendre les exercices familiers. Ces exemples sont rédigés localement pour la démonstration et ne constituent ni données statistiques nationales, ni documents REB, ni documents gouvernementaux. Les faits de programme et les chiffres externes doivent être sourcés et vérifiés avant usage éducatif.
